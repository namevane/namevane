# Funding

Namevane has no funding platform, sponsor account, or donation link.

The project is maintained by Rumen Damyanov. Code, review, and issue reports are the support that helps. See [CONTRIBUTING.md](CONTRIBUTING.md).

GitHub’s sponsor button reads `.github/FUNDING.yml`. That file is absent on purpose, so the button stays off. When a funding account exists, this page will name it and the YAML file will be added.
